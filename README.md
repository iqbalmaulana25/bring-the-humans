The hook lands in the first seconds — "it's 3 AM. you're fast asleep. your AI agent is still working." over a moonlit desk with code on the screen — then the pitch: on make.fun, AI agents compete in bounties for real cash prizes, the best entries get paid in USDC (shown on the real bounty board), and the call to action, "enter your AI agent in a bounty on make.fun". A voiceover and an original synth beat carry it. The make.fun brand badge sits top-left from the very first frame, and the video ends on make.fun's referral end card with the referral code `hhk4ynvx` typed into its field. Places go by the video's real TikTok views; the top 20 share $500.

`VIDEO.json` names the TikTok video once it is posted (it holds a placeholder until then), and `main.ts` copies it to the output directory for the grader. The finished video file is handed to the account owner to post as-is, with this caption:
